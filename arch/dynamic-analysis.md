# 로컬 자동 정적·동적 분석

현재 구현은 React 대시보드와 Gmail FastAPI를 재사용한다. 각 팀원이 자기 PC에서 실행하며
자동 동적 분석은 로컬 Ollama만 사용한다. 별도 클라우드 서버·공유 원격 셸은 추가하지 않는다.

## 실행 흐름

1. CSRF로 보호된 POST 메일 수집이 암호화된 정적 대기열에 등록한다. GET 조회는 등록하지 않는다.
2. 팀 커밋 `3e8968e`의 기존 ML과 BERT-tiny Transformer를 별도 Python 3.12 환경에서 실행한다.
3. 확률의 최댓값 대신 각 모델 임계값으로 낸 위험 단계의 최댓값을 최종 판정으로 사용한다.
4. 계정별 자동 설정을 켠 의심·위험 메일만 Ollama 동적 대기열에서 순차 실행한다.
5. 모델의 run_shell 요청을 검증하고 메일마다 새 Docker 안에서 실행한다.
6. 대시보드에서 모델별 점수·최종 판정·명령·stdout/stderr·파일 변경·고정 목표 관찰을 확인한다.

긴 명령 출력은 최대 256KiB까지 암호화 로그에 보관하고 모델에는 예산에 맞는 미리보기와
`read_output` 페이지 조회를 제공한다. 실험별 출력 저장은 1MiB로 제한한다. 오래된 대화 묶음은
현재 모델 입력에서 제외될 수 있고 원본 로그에는 남는다. 각 추론의 `model_input`과
`context_window` 이벤트를 기록해 원본 출력과 모델이 실제 받은 내용을 구분한다.

동적 화면은 자동 실행 조회·중지·JSON 다운로드와 별도 합성 메일 쌍 평가를 제공한다. 이전 수동 실험 기록과 외부 API
백엔드는 호환을 유지하며 새 합성 정상/공격 쌍 입력과 그룹 지표를 제공한다.
유료 API 자동 전환은 제공하지 않는다. [합성 평가 안내](../src/gmail/docs/synthetic-evaluation.md).

## 모델과 중복 방지

팀 ML·Transformer 가중치는 별도 공유 파일을 models/에 배치하며 Git에서는 제외한다. 기본 팀 모델의 Transformer가 없거나
일부 파일이 누락되면 준비 실패로 남기며 safe로 통과시키지 않는다. 명시적 외부 단일 ML
아티팩트는 기존 호환 용도로만 지원한다. 가중치·설정·토크나이저 전체를 정적 모델 식별자에 포함한다.

메일·전체 입력 해시·정적 모델·설정·Ollama 모델 정보로 중복을 확인한다. 수집 전에
Ollama 모델 정보를 갱신하고, 실행 직전에도 저장한 모델 정보와 일치하는지 검사한다.
모델/설정이 바뀌면 이전 작업을 중지하고 새 세대의 결과를 생성한다.

## 격리와 데이터

- Ollama는 호스트에서 추론한다. 모델 문자열을 호스트 셸에서 실행하지 않는다.
- 셸 명령은 네트워크 없음, 비관리자, 읽기 전용 루트의 일회용 Linux 컨테이너에서 실행한다.
- 호스트 폴더·Docker 소켓·API 키·Gmail 토큰을 컨테이너에 전달하지 않는다.
- 이미지 실제 ID를 고정하고 선언 볼륨을 거부하며 입력 전에 실제 마운트를 검사한다.
- 동시 1개, CPU/RAM/PID/시간/출력 제한을 적용한다. 호스트 Ollama 자원은 이 제한 밖이다.
- 알려진 환경 제거 실패는 다음 실행을 막고 서버 재시작 시 다시 제거한다.
- 대기 본문과 새 실행 기록은 기존 키로 암호화한다. 명령·출력은 실제 메일 내용을 포함할 수 있다.
- 오류·미관찰은 정적 위험 판정을 낮추지 않는다. leak.txt 관찰은 모든 유출 경로를 뜻하지 않는다.
- Docker/VM 런타임 취약점까지 포함한 완전한 격리를 보장하지 않는다.

## 준비와 검증

`src/gmail/docs/automatic-analysis.md`와 `dynamic-analysis.md`에서 설치·실행·관찰 한계를 설명한다.
설치된 qwen3:4b의 추론 전용 제약을 확인하고 qwen3:4b-instruct로 합성 메일 전체 흐름을 검증했다.
정상 샘플의 정적 오탐도 관찰했으므로 기능 연결 검증을 탐지 정확도 평가로 해석하지 않는다.

`feat/jihun`에서 develop의 수집·탐지·Supabase 어댑터와 통합했다. POST `/api/mails`는
자동 분석 대기열을 사용하고 GET 조회와 명시적 POST `/api/sync`는 기존 탐지 계약을 유지한다.
`/api/sync`는 동적 분석을 등록하지 않으며 고정 테스트 사용자 설정을 쓰는 데모 어댑터다.
# 전용 VM 실행 대상 (2026-10-29 추가)

현재 Mac에서는 로그인 없는 Lima/VZ `prodog-lab` VM 안에 독립 rootless Docker 엔진을 두고,
실행 기록의 `sandbox_context=prodog-vm`으로 명령·관측·정리 대상을 고정할 수 있다.
Ollama·Gmail·React·분석 제어기는 호스트에 남고 공유 폴더와 SSH agent는 전달하지 않는다.
VM은 유지하며 메일별 컨테이너만 새로 만든다. 네트워크 차단은 컨테이너에 적용되며 VM의 초기
설치용 NAT까지 제거한 구성은 아니다. [준비 및 검증](../src/gmail/docs/local-vm.md)을 따른다.
